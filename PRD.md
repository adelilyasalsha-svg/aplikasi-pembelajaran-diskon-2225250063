# Product Requirements Document
# Aplikasi Pembelajaran Diskon

## 1. Informasi Produk

Nama Produk: Aplikasi Pembelajaran Diskon

Kategori: Media Pembelajaran Matematika

Target Pengguna: Siswa SMP Kelas 7

Topik: Aritmetika Sosial - Diskon

Platform: Website

## 2. Latar Belakang

Pembelajaran matematika membutuhkan media yang menarik dan interaktif agar siswa lebih mudah memahami materi.

Aplikasi Pembelajaran Diskon dikembangkan sebagai media pembelajaran berbasis website yang membantu siswa mempelajari konsep diskon melalui materi, latihan soal, evaluasi, kalkulator, dan permainan edukatif.

## 3. Tujuan Aplikasi

1. Membantu siswa memahami konsep diskon.
2. Membantu siswa menghitung potongan harga.
3. Meningkatkan minat belajar matematika.
4. Memberikan pengalaman belajar interaktif.
5. Mengukur pemahaman siswa melalui evaluasi.

## 4. Target Pengguna

Target utama aplikasi adalah siswa SMP kelas 7 yang sedang mempelajari materi diskon dalam matematika.

## 5. Fitur Utama

### A. Identitas Siswa
Siswa memasukkan nama dan kelas sebelum menggunakan aplikasi.

### B. Dashboard
Menampilkan sambutan dan pilihan menu pembelajaran.

### C. Materi
Berisi:
- Pengertian diskon.
- Rumus diskon.
- Cara menghitung diskon.
- Contoh soal dan pembahasan.

### D. Pretest
Digunakan untuk mengetahui kemampuan awal siswa sebelum mempelajari materi.

### E. Latihan
Berisi soal interaktif untuk menguji pemahaman siswa.

### F. Posttest
Digunakan untuk mengukur pemahaman siswa setelah mempelajari materi.

### G. Kalkulator Diskon
Membantu siswa melakukan perhitungan diskon dan memahami langkah-langkahnya.

### H. Game Edukasi
Permainan bertema belanja yang mengajak siswa menerapkan konsep diskon.

### I. Musik
Menyediakan kontrol untuk mengaktifkan atau menonaktifkan musik pembelajaran.

## 6. Kebutuhan Fungsional

- Siswa dapat memasukkan identitas.
- Siswa dapat mengakses seluruh menu pembelajaran.
- Siswa dapat membaca materi.
- Siswa dapat mengerjakan soal.
- Sistem dapat memeriksa jawaban.
- Sistem dapat menampilkan hasil evaluasi.
- Siswa dapat menggunakan kalkulator.
- Siswa dapat memainkan game edukasi.
- Aplikasi dapat menggunakan Supabase sesuai konfigurasi proyek.

## 7. Kebutuhan Nonfungsional

- Tampilan mudah dipahami.
- Aplikasi responsif.
- Navigasi mudah digunakan.
- Warna dan desain konsisten.
- Aplikasi dapat diakses melalui browser.
- Data dan konfigurasi harus dijaga keamanannya.

## 8. Teknologi yang Digunakan

- React
- Vite
- JavaScript
- CSS
- Supabase
- GitHub
- Vercel

## 9. Alur Penggunaan

1. Siswa membuka aplikasi.
2. Siswa memasukkan nama dan kelas.
3. Siswa masuk ke dashboard.
4. Siswa memilih menu pembelajaran.
5. Siswa mempelajari materi dan mengerjakan aktivitas.
6. Siswa menggunakan kalkulator atau game.
7. Siswa mengerjakan posttest.
8. Siswa melihat hasil pembelajaran.

## 10. Indikator Keberhasilan

- Aplikasi dapat dibuka dengan baik.
- Seluruh menu dapat diakses.
- Materi dapat ditampilkan.
- Soal dapat dikerjakan.
- Hasil evaluasi dapat ditampilkan.
- Kalkulator dan game dapat digunakan.
- Tampilan berjalan dengan baik di berbagai perangkat.

## 11. Pengembangan Selanjutnya

Pengembangan dapat dilakukan dengan menambahkan variasi soal, materi tambahan, laporan hasil belajar, dan fitur pendukung pembelajaran lainnya.
