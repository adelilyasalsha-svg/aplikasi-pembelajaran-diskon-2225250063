# Desain Aplikasi Pembelajaran Diskon

## 1. Konsep Desain
Aplikasi Pembelajaran Diskon menggunakan konsep desain Purple Candy dengan tampilan ceria, modern, sederhana, dan ramah bagi siswa SMP kelas 7.

Desain dibuat agar kegiatan belajar matematika terasa lebih menarik dan mudah dipahami.

## 2. Tema Warna

Tema utama: Purple Candy

| Elemen | Warna | Kode |
|---|---|---|
| Background utama | Putih lavender | #F7F4FC |
| Ungu utama | Purple | #8B5BD6 |
| Ungu gelap | Dark Purple | #6540A5 |
| Materi | Ungu pastel | #C5A5F0 |
| Pretest | Kuning pastel | #FFE4A3 |
| Latihan | Pink pastel | #F8C5D9 |
| Posttest | Hijau pastel | #BFE8CF |
| Kartu konten | Putih | #FFFFFF |

## 3. Tipografi
Aplikasi menggunakan:
- Fredoka untuk judul.
- Nunito untuk teks dan isi konten.

Kedua font dipilih agar tampilan terlihat menarik dan mudah dibaca.

## 4. Komponen Desain

### Header
Menampilkan identitas aplikasi, informasi siswa, dan tombol keluar.

### Halaman Identitas
Digunakan siswa untuk memasukkan nama dan kelas sebelum memulai pembelajaran.

### Dashboard
Menampilkan sambutan dan menu pembelajaran.

### Menu Pembelajaran
Terdiri dari:
- Materi
- Pretest
- Latihan
- Posttest

Setiap menu menggunakan warna pastel yang berbeda.

### Materi
Menampilkan penjelasan konsep diskon, rumus, dan contoh soal.

### Kalkulator
Membantu siswa memahami proses perhitungan diskon.

### Game
Menyediakan permainan edukatif bertema belanja dan diskon.

## 5. Bentuk Komponen
- Kartu menggunakan sudut membulat.
- Tombol menggunakan warna ungu.
- Konten menggunakan latar putih.
- Bayangan dibuat lembut.
- Ikon dan ilustrasi digunakan sebagai pendukung pembelajaran.

## 6. Responsivitas
Aplikasi dirancang agar dapat digunakan melalui:
- Komputer atau laptop.
- Tablet.
- Smartphone.

Tampilan menyesuaikan ukuran layar perangkat.

## 7. Prinsip Desain
- Sederhana dan mudah digunakan.
- Konsisten pada setiap halaman.
- Memiliki kontras warna yang jelas.
- Menarik bagi siswa.
- Mendukung pengalaman belajar interaktif.
